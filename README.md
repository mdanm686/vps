## 线路：为什么同样叫“CN2”，晚高峰表现能差一截

因为 CN2 本身分两档，而很多标“CN2”的方案用的是便宜那档。CN2 GT 走中档线路，国内段跑 CN2，国际段可能交给其他转接，北京时间晚上七点到十一点的高峰期，延迟和丢包会明显恶化。CN2 GIA 全程走 59.43 的 CN2 骨干、独享容量，普通线路堵成一锅粥的时候它还能维持住。

GoMami 用的不是单一 CN2，而是 CN2 / AS9929（联通）/ CMIN2（移动）三条精品回程组合，官方给的目标是中国大陆全境 RTT 低于 50ms。第三方测评记录到的走向是：电信去程 163 / CN2、回程 CN2；联通去程 4837、回程 9929；移动去程 CMI、回程 CMIN2，晚高峰回程仍维持精品路由。这组数据只有一个来源，参考价值有，但别当成保证——不同省份、不同运营商的体验差别不小。

想自己验证，官方有独立的 Looking Glass 页面，可以选节点跑 Ping、TCPing、MTR、NextTrace 和 Traceroute。下单前花十分钟测一下自己所在运营商到香港的实际延迟，比看十篇测评都直接。
